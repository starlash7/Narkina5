# Narkina5 AI Agent

블록체인과 AI 기술의 융합을 통해 혁신적인 솔루션을 제공하는 AI 에이전트입니다.

## 기능

- 🤖 AI Agent 기반 대화 시스템
- 🔗 블록체인 및 DeFi 전문 지식
- 💬 한국어 대화 지원
- 🚀 ElizaOS 프레임워크 기반

## 설치 및 실행

```bash
# 의존성 설치
bun install

# Narkina5 Agent 실행
cd eliza/examples
export OPENAI_API_KEY="your-api-key"
bun run narkina5-standalone.ts
```

## 기술 스택

- ElizaOS
- TypeScript
- Bun
- OpenAI API
- PGLite (로컬 데이터베이스)

## 프로젝트 구조

- `eliza/` - ElizaOS 프레임워크
- `eliza/examples/narkina5-standalone.ts` - Narkina5 채팅 앱
- `eliza/examples/narkina5-chat.ts` - Narkina5 채팅 앱 (고급 버전)
